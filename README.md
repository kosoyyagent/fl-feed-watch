# fl-feed-watch

Монитор новых заказов FL.ru и Kwork → уведомления в Telegram.

Периодически опрашивает публичные ленты заказов (FL.ru, Kwork), фильтрует
новые по ключевым словам (regex) и шлёт ботом в указанный чат/канал/группу.
Префикс источника в сообщении: «Новый заказ FL» / «Новый заказ Kwork».
Дедупликация через sqlite — один заказ не придёт дважды.

## Запуск

```bash
pip install -r requirements.txt
set TG_TOKEN=123:abc          # токен бота @BotFather
set CHAT_ID=-1001234567890    # куда слать (бот должен уметь писать туда)
set KEYWORDS=бот|парсер|python # regex-фильтр по заголовку+описанию
set ONCE=1                    # один прогон (для cron); без флага — демон
python fl_feed_watch.py
```

Или `config.json` рядом — см. `config.example.json`.

`FEED_URLS` — список лент через запятую (по умолчанию: две ленты FL.ru +
kwork.ru/projects — парсит embedded-JSON публичной страницы). `INTERVAL` — пауза между опросами в сек (по умолчанию 300).

## Замечания

- Парсит публичную ленту — авторизация не нужна.
- Новые заказы помечаются в seen.db ДО фильтра — смена regex не поднимет
  историю (удалите seen.db для полного пересмотра).
- Лимит TG: пауза 1с между отправками + retry_after на 429.
